# create-pr

プルリクエストを作成するためのコマンドです。

## 使い方

```
/create-pr
```

## 処理内容

1. 現在のブランチの変更内容を確認する
2. コミットログからPRタイトルと概要を生成する
3. PRテンプレートに従って説明文を作成する
4. `gh pr create` でプルリクエストを作成する

## PR作成ルール

- タイトルは70文字以内
- ベースブランチは `main`
- レビュアーは自動アサインしない（手動で指定する）
- ラベルは変更の種類に応じて付与する（`feat`, `fix`, `docs`, `chore` など）

## テンプレート

```markdown
## Summary
- 変更の概要

## Changes
- 具体的な変更内容

## Test plan
- [ ] 動作確認済み
- [ ] テスト追加済み（該当する場合）
```
