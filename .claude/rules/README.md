# rules

このディレクトリには、プロジェクトにおけるClaudeの行動規範・運用方針を定義したルールファイルが格納されています。

## ファイル一覧

| ファイル | 内容 |
|---|---|
| `architecture.md` | システムアーキテクチャとコンポーネント構成の方針 |
| `coding.md` | コーディング規約とベストプラクティス |
| `development-flow.md` | 開発フローとブランチ戦略 |
| `git.md` | Gitの操作ルールとコミットメッセージ規約 |
| `infrastructure.md` | インフラ構成と環境管理の方針 |
| `mcp.md` | MCPサーバーの設定と利用ルール |

## 運用方針

- 各ルールファイルはプロジェクトの実態に合わせて随時更新する
- 重要な変更はプルリクエストでレビューを行う
- Claudeはこれらのルールをタスク実行時に参照する
