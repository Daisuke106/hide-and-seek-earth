# インフラ方針

## 環境構成

| 環境 | 用途 |
|---|---|
| local | ローカル開発環境（Docker） |
| staging | 動作確認・QA環境 |
| production | 本番環境 |

## Docker 構成

```yaml
# docker-compose.yml の主なサービス
# - app: PHPアプリケーションサーバー
# - db: データベース
# - nginx: Webサーバー
```

### ローカル環境の起動

```bash
docker-compose up -d
```

## 環境変数の管理

- `.env` ファイルはGitにコミットしない
- `.env.example` にサンプル値を記載してGit管理する
- 機密情報は各環境のシークレット管理サービスで管理する

## CI/CD

GitHub Actions を使用する。

### ワークフロー

- **PRオープン時**: リント・テスト・型チェックを実行する
- **mainマージ時**: ステージング環境へ自動デプロイする
- **リリースタグ作成時**: 本番環境へデプロイする
